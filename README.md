# Visual Preference Research Study

6 images → select exactly 3. Research survey style. Share link from anywhere.

## Quick start

1. **ADD-YOUR-IMAGES.bat** — add `1.jpg` … `6.jpg` to `images/` folder
2. **START-SURVEY.bat** — test on PC (`http://localhost:8080`)
3. Results: `http://localhost:8080/admin` (key: `research2026`)

## Deploy link (Vercel)

1. GitHub eke repo create karala files upload karanna
2. https://vercel.com → Import project → Deploy
3. Vercel → Storage → Upstash Redis connect karanna (responses save wenna)
4. Share link: `https://your-app.vercel.app/`
